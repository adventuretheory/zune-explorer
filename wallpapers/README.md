# Zune HD wallpapers

Original wallpapers in the Zune style, made for this fork. Each is
272 × 480 (the Zune HD screen, upright).

- dusk-record-tree
- spiro-orbits
- funk-burst
- ribbon-flow
- equalizer-city
- retro-sun-grid

## Putting one on the Zune

1. In the app: settings → library → picture folders → + add folder, and pick
   this `wallpapers` folder.
2. Open the Zune panel → PHOTOS, select the wallpapers and sync them.
3. On the Zune: open the picture in Pictures and set it as the background.
